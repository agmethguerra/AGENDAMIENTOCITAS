# Sistema de Citas - Caballeros Barbería

Proyecto organizado con buenas prácticas y estructura modular.

## Estructura

- index.html → Vista principal
- assets/css/styles.css → Estilos del proyecto
- assets/js/app.js → Lógica de la aplicación
- config/firebase.js → Configuración de Firebase

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript Vanilla
- Firebase Firestore

## Funcionalidades

- Agenda de citas
- Panel administrador
- Gestión de barberos
- Gestión de citas
- Integración con WhatsApp
- Persistencia con Firebase

## Recomendaciones

1. No subir credenciales reales a producción.
2. Usar Firebase Authentication para administradores.
3. Configurar reglas seguras de Firestore.
4. Separar lógica en módulos adicionales si el proyecto crece.
